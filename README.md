## Sobre mí

Desarrollo aplicaciones web, de escritorio y móviles desde Ecuador. Me interesan especialmente las utilidades de Windows, la automatización, los sistemas para negocios y las experiencias que hacen más sencillas las tareas cotidianas.

**Mi enfoque:** diseñar, programar, probar, documentar y mejorar. Este perfil reúne tanto software disponible como iniciativas privadas que todavía están en desarrollo.
